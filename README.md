# 🏥 HealthConnect Clinic - Patient Attendance Analysis

## AnalystLab Africa - Experience Lab

---

## 📌 Project Overview

HealthConnect Clinic is a healthcare provider experiencing high patient no-show rates. This project aims to analyze appointment data to identify factors associated with missed appointments and develop data-driven recommendations to improve patient attendance.

---

## 🎯 Project Goal

> "How can HealthConnect Clinic use data and AI to reduce missed appointments and improve the patient support experience?"
